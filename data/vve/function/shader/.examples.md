# VVE roll datapack examples

These functions are examples for controlling the shader roll-angle interface from a datapack.

The intended angle interface uses `angle int` as input:

```mcfunction
scoreboard players set angle int 45
function vve:shader/roll_linear_from_angle

scoreboard players set angle int -45
function vve:shader/roll_linear_from_angle

scoreboard players set angle int 90
function vve:shader/roll_instant_from_angle
```

The generic macro functions take an encoded ARGB color directly:

```mcfunction
function vve:shader/roll_linear {color:-67175360}
function vve:shader/roll_instant {color:-67175616}
```

Angle encoding:

```text
normalized = ((angle % 360) + 360) % 360
linear value = round(normalized * 256 / 360) % 256
linear color = -67175424 + linear value
instant value = round(normalized * 255 / 360) % 256
instant color = -67175680 + instant value
```

Copy this `data` folder into a datapack if you want callable functions. The resource pack itself only provides the shader pipeline.
