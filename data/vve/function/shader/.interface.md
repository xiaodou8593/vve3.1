# VVE roll angle shader interface

This resource pack integrates a modified ShaderSelectorV4 pipeline. It exposes one roll-angle channel:

| Channel | Marker green | Operation |
| --- | ---: | --- |
| `VVE_ROLL_ANGLE_CHANNEL` | 251 | Set instantly |
| `VVE_ROLL_ANGLE_CHANNEL` | 252 | Linear cyclic interpolation |

The shader computes:

```text
screen roll angle = channel_value * 360 degrees
```

`0` degrees is the default level screen. Negative angles are encoded by wrapping around 360 degrees.

## Angle encoding

Convert a roll angle in degrees to the particle blue byte.

For linear cyclic rotation (`green=252`, `op=2`), use:

```text
normalized = ((angle % 360) + 360) % 360
value = round(normalized * 256 / 360) % 256
linear ARGB = -67175424 + value
```

For instant set (`green=251`, `op=0`), use:

```text
normalized = ((angle % 360) + 360) % 360
value = round(normalized * 255 / 360) % 256
instant ARGB = -67175680 + value
```

## Scoreboard angle interface

The example datapack includes functions that take an angle from the scoreboard and compute the particle color automatically. The linear roll marker uses constant-speed cyclic interpolation and takes the shortest path across 0/360 degrees.

Set the target angle in degrees:

```mcfunction
scoreboard players set angle int 45
function vve:shader/roll_linear_from_angle
```

Use a negative angle:

```mcfunction
scoreboard players set angle int -45
function vve:shader/roll_linear_from_angle
```

Set the angle instantly instead of linearly:

```mcfunction
scoreboard players set angle int 90
function vve:shader/roll_instant_from_angle
```

The example datapack initializes the `int` objective from its load function:

```mcfunction
function vve:shader/setup
```

## Function macro wrapper

Minecraft function macros cannot do arithmetic, so the macro wrapper takes the already encoded ARGB color:

```mcfunction
function vve:shader/roll_linear {color:-67175360}
function vve:shader/roll_instant {color:-67175616}
```

The macro emits the marker at `^ ^ ^`; call it from the execution context where the marker should appear.
