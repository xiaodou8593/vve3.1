# 木板

模块：`vve_examples:board`  
代码：`data/vve_examples/function/board/`

木板是盒状张量刚体示例。它使用 `box_object` 的惯性张量计算和四角碰撞点，以橡木板显示实体表现长、薄、宽的物体。

## 实现要点

- `_class` 设置缩放 `(1, 0.1, 2)`、质量 `50`，并调用 `vve:box_object/_calc_tensor_i` 生成惯性张量。
- `_iter_cpoints` 在木板局部坐标系中遍历角点并探测介质。
- `set_operation` 将橡木板物品写入显示实体；物理实体本身是 `item_display`。
- `test/` 覆盖碰撞点、下落、浮力、相互反弹和推动。
