# 实心六面骰子

模块：`vve_examples:dice_6_s`  
代码：`data/vve_examples/function/dice_6_s/`

实心六面骰子使用 `cublock` 风格的实体介质刚体。与普通六面骰子相比，它本身带有可被其他物体探测的实心身份，并使用立方体碰撞点和外部冲量接收器。

## 实现要点

- `_class` 设置立方体缩放、质量、惯量和质心偏移。
- `_iter_cpoints` 遍历立方体顶点，接收反弹层、附着层、摩擦、位移和冲量响应。
- `main_c` 负责刚体运动、外部冲量、摩擦和显示同步，并在运动期间维护 `vve_material_box` 标签。
- 模块初始化时注册 `module_control`，可被动态接口调用。

## 测试

```mcfunction
function vve_examples:dice_6_s/test/cp/start
function vve_examples:dice_6_s/test/fall/start
function vve_examples:dice_6_s/test/float/start
function vve_examples:dice_6_s/test/inter_bounce/start
function vve_examples:dice_6_s/test/push/start
```

这些场景适合对比普通 `dice_6`：前者验证实体介质和多物体碰撞，后者主要验证骰子自身的滚动和读值。
