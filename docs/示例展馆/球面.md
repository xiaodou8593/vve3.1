# 球面

模块：`vve_examples:sphere`  
代码：`data/vve_examples/function/sphere/`

球面是实体介质示例。它使用半径 `r` 和缩放参数生成球形探测范围，可作为其他物体的碰撞环境；显示乘客会在 `set_operation` 中被移除，因此物理球面可以独立于视觉模型存在。

## 实现要点

- `_class` 设置默认半径并调用 `_calc_scale` 计算缩放。
- `check_material`、`response` 和 `_proj` 组成材质探测与响应流程。
- 实例注册 `module_control`，并带有 `vve_large_material` 标签以支持大型介质探测。
- `test/display_1` 将半径放大到 `r=50000`，用于验证大型球面的显示和探测。

## 测试

```mcfunction
function vve_examples:sphere/test/display/start
function vve_examples:sphere/test/display_1/start
```

测试需要图形库时，可以观察球面碰撞范围；没有图形库时仍可验证实体介质响应。
