# 绿车

模块：`vve_examples:green_car`  
代码：`data/vve_examples/function/green_car/`

绿车是带资源包模型、声音和轮组状态的完整载具示例。其物理控制与测试车相近，但显示、座椅偏移、控制信号和声音程序均进行了独立定制。

## 实现要点

- `_class` 设置车身尺寸、转弯半径、发动机阻尼和速度上限。
- `set_operation` 使用 `bx_res_bca:vehicle_0` 物品模型，并配置座椅宽高。
- `control/` 与 `sound/` 分别处理输入控制和摩擦/反弹声音。
- `wheel_state` 保存轮组显示或控制状态；`_ride_on_nearest`、`_seat_on` 等接口用于载具操作。

## 测试与依赖

```mcfunction
function vve_examples:green_car/test/cp/start
function vve_examples:green_car/test/fall/start
function vve_examples:green_car/test/float/start
function vve_examples:green_car/test/inter_bounce/start
function vve_examples:green_car/test/push/start
```

完整外观依赖资源包中的 `bx_res_bca:vehicle_0` 物品模型；没有该资源包时仍可检查物理和座椅逻辑，但显示模型不会正确呈现。
