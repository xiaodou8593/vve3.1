# 多米诺骨牌

模块：`vve_examples:domino`  
代码：`data/vve_examples/function/domino/`

多米诺骨牌是带实体介质身份的盒状刚体。它在木板的张量盒体思路上增加 `cubox` 的质心偏移、碰撞响应和可被其他物体探测的方块介质标签。

## 实现要点

- `_class` 设置长薄盒体尺寸、质量 `50` 和惯性张量。
- `_new` 创建 `interaction` 根实体及其 `item_display` 乘客；根实体承担物理状态。
- `set_operation` 使用骨块显示，并设置 `vve_material_type`。
- `test/push_1` 可观察骨牌在连续推动场景中的响应。
