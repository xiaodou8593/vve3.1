# 打水漂

模块：`vve_examples:skip_stone`  
代码：`data/vve_examples/function/skip_stone/`

打水漂是质点式示例。它只保存中心、线速度和质量，不计算自身旋转，用一个中心碰撞点近似石片与水面的接触。

## 实现要点

- `_class` 使用 `vve:point` 的锚定方式，默认质量为 `1`。
- `main*` 主要推进质点位置、重力和介质响应。
- `_regular` 根据介质法向选择贴合方向，用于水面接触后的轨迹修正；显示仍使用石按钮物品。
- `float_push` 测试水面浮力与外部推动组合。

## 测试

该示例适合用来说明：视觉上可以是石片，但物理模型仍可能是没有姿态的质点。
