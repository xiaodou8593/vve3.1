# 四面骰子

模块：`vve_examples:dice_4`  
代码：`data/vve_examples/function/dice_4/`

四面骰子是标量惯量刚体与骰子功能的组合示例。模块用四个顶点作为碰撞点，使用四组局部方向判断朝上的面，并提供随机姿态、投掷和点数读取接口。

## 实现要点

- `_class` 设置边长参数 `a`、质量和标量惯量，并生成 `dice_4_plate`。
- `_iter_cpoints` 将四个局部顶点转换到世界坐标后逐点探测介质。
- `main_c` 按运动学迭代、介质探测、力学响应和运动同步的顺序推进实体。
- `_get_value` 将局部方向旋转到世界空间，选择最高的方向对应的点数。

## 测试

`test/cp` 验证四个碰撞点的运动。测试入口为：

```mcfunction
function vve_examples:dice_4/test/cp/start
```

测试脚本会初始化 VVE 和本模块，再通过 `marker_control` 调度测试实体。
