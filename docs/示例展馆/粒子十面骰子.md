# 粒子十面骰子

模块：`vve_examples:dice_10`  
代码：`data/vve_examples/function/dice_10/`

粒子十面骰子是十面多面体刚体与自定义渲染的组合示例。物理状态仍由实体刚体保存，但模型轮廓、碰撞点或标签可以通过粒子/文本渲染辅助观察。

## 实现要点

- `_class` 设置十面体的质量、标量惯量和几何参数。
- `regular/` 保存十个面的稳定方向；`label/` 管理面值标签的生成和传送。
- `_render`、`render_line` 和 `render_callback` 将几何或面值绘制到图形库接口。
- `test/fall`、`float`、`inter_bounce` 和 `push` 覆盖基本环境、流体、碰撞和外部冲量。

## 测试

function vve_examples:dice_10/test/cp/start
