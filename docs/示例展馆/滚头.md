# 滚头

模块：`vve_examples:roll_head`  
代码：`data/vve_examples/function/roll_head/`

滚头是使用玩家头颅显示的标量惯量刚体示例。它在普通滚动、介质探测和姿态修正之外，增加了摄像机实体、旁观视角和相机同步接口，便于近距离观察滚动过程。

## 实现要点

- `_class` 使用半径参数 `a`、质量 `17` 和标量惯量 `500`。
- `_iter_cpoints_*` 提供普通、慢速和流体环境下的碰撞点探测，并可向图形库输出碰撞点。
- `set_operation` 设置玩家头颅显示，并为实例创建相机实体。
- `cam_set`、`_spectate`、`_spectate_nearest` 和 `exit_spectating` 管理观察视角。
