# 十二面骰子

模块：`vve_examples:dice_12`  
代码：`data/vve_examples/function/dice_12/`

十二面骰子是更复杂方向表的骰子示例。除刚体运动外，模块还包含随机四元数、固定姿态、点数读取和结果打印回调。

## 实现要点

- `_class` 提供标量惯量刚体的默认模板。
- `_regular` 与 `_get_value` 使用十二面方向表处理稳定姿态和朝上面判定。
- `_roll`、`_roll_fixed`、`_rand_quat` 和 `_set_quat` 组成投掷与重复实验接口。
- `get_value_loop` 和 `rand_quat_loop` 负责分步处理点数读取及随机姿态计算。
