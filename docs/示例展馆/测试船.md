# 测试船

模块：`vve_examples:test_boat`  
代码：`data/vve_examples/function/test_boat/`

测试船是载具模板在水面控制场景中的示例。它使用盒状惯性张量、座椅、发动机和水面/空中两套控制逻辑。

## 实现要点

- `control/main_water` 处理水中控制，`main_surface` 和 `main_air` 处理水面及空中状态。
- `engine/` 根据目标动力、阻尼和速度上限推进船体。
- `_new` 创建显示实体及交互座椅；`set_operation` 设置海晶灯显示和座椅高度。
- `test/pool` 专门验证水池环境中的漂浮和控制行为。
