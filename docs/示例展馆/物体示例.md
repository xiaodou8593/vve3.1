# 物体示例

本页汇总 `vve_examples` 中可以作为动态物体观察的示例。它们都以 VVE 的物体生命周期为基础：由 `_class` 提供默认数据模板，`_new` 创建实体，`main*` 执行物理迭代，`_update_display` 同步显示。

骰子系列展示不同多面体的碰撞点、姿态判定和点数读取；木板、骨牌、史莱姆方块和打水漂展示不同的刚体或质点建模取舍；三种载具展示发动机、座椅、输入和水面控制；滚头与大懒灯则展示旁观视角和动态模块回调。

每个展品的自动化场景位于对应模块的 `test/` 目录。测试入口通常是 `function vve_examples:<模块>/test/<场景>/start`，具体场景以各展品页面为准。
