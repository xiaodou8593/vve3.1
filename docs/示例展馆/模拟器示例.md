# 模拟器示例

VVE 示例中的模拟器是独立的调度模块，不是物理实体。它们保存模拟时间倍率、拆分相位、常量覆盖和回调列表，然后在每个游戏刻中按自己的规则运行物体。

## 两个示例

- [dice_simulator](dice_simulator.md)：固定调度 `dice_4`、`dice_6`、`dice_8` 和 `dice_12`，使用更适合骰子滚动的摩擦参数。
- [car_simulator](car_simulator.md)：固定调度测试车、绿车和测试船，使用更高的切向摩擦参数。

两个模拟器都使用 `vve_simulator_1.0` 风格的 `_get → _consts → main_loop → _store` 流程。它们应依次完整运行，不能在一个模拟器尚未保存状态时嵌套启动另一个模拟器。
