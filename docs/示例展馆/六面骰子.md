# 六面骰子

模块：`vve_examples:dice_6`  
代码：`data/vve_examples/function/dice_6/`

六面骰子是常规骰子功能的标量惯量刚体示例。它使用六面显示模型和八个顶点碰撞点，支持姿态生成、投掷、点数读取及朝向稳定测试。

## 实现要点

- `_class` 默认设置 `a=2500`、质量 `17`、惯量 `500`。
- `_get_value` 根据六个面方向返回当前朝上的点数。
- `_iter_cpoints_render` 除介质探测外还可把碰撞点交给图形库渲染，便于检查几何。
- `test/spring` 在关闭重力的环境中观察两个骰子的弹簧式接触测试。

## 测试

```mcfunction
function vve_examples:dice_6/test/cp/start
function vve_examples:dice_6/test/spring/start
```

`cp` 关注碰撞点和姿态，`spring` 关注无重力条件下的接触行为；两个场景都需要按测试脚本要求准备图形库或依赖。
