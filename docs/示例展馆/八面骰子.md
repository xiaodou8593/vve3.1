# 八面骰子

模块：`vve_examples:dice_8`  
代码：`data/vve_examples/function/dice_8/`

八面骰子展示双锥体骰子的姿态和面值判定。它沿用标量惯量刚体和骰子功能接口，以八个方向表项完成朝上面检测。

## 实现要点

- `_class` 生成 `dice_8_plate` 默认数据模板。
- `_iter_cpoints` 使用多面体顶点进行介质探测。
- `_get_value`、`_rand_quat` 和 `_set_quat` 共享同一套方向约定，保证显示姿态、随机投掷和读值一致。
