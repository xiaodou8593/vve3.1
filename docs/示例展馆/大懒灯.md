# 大懒灯

模块：`vve_examples:impulse_lamp`  
代码：`data/vve_examples/function/impulse_lamp/`

大懒灯是动态实体介质和模块回调的示例。它以方块盒体为物理对象，接收冲量时触发灯光状态，并通过 `module_control` 注册动态调用接口。

## 实现要点

- `_new` 创建 `interaction` 根实体和 `block_display` 灯体乘客。
- `set_operation` 设置红石灯方块显示、材质类型和模块 ID。
- `response`、`return_impulse`、`main_on` 和 `main_off` 组成冲量响应与亮灭状态机。
- `light_duration` 控制点亮持续时间；`light/` 子目录保存灯光辅助对象。
- `test/this` 验证同一函数上下文中显示变换的更新行为。
