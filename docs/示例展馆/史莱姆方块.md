# 史莱姆方块

模块：`vve_examples:slime_block`  
代码：`data/vve_examples/function/slime_block/`

史莱姆方块是带弹性和缩放状态的盒状刚体示例。它在实体刚体运动之外，为接触冲量加入阻尼、形变缩放和弹性恢复过程。

## 实现要点

- `_class` 使用盒体惯性张量，默认显示史莱姆方块。
- `main_scale` 根据接收冲量计算压缩方向、弹力和质心受力，并在迭代收敛后恢复缩放。
- `_apply_friction` 同时处理线速度和角速度的摩擦缩放。
- `main_l` 与 `_iter_cpoints_l` 提供流体环境下的浮力路径，`main_slow_*` 支持拆分时间。
