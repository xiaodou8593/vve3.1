# 测试车

模块：`vve_examples:test_car`  
代码：`data/vve_examples/function/test_car/`

测试车是张量盒体载具示例。它包含八个底盘碰撞点、发动机阻尼、水平转向、玩家输入和座椅层级，主要用于验证载具模板的控制与贴地姿态。

## 实现要点

- `_class` 默认车身尺寸为 `(1, 0.6, 2)`，质量为 `50`，并设置发动机和最大速度参数。
- `_iter_cpoints_c` 将碰撞点分为可位移和不可位移集合，供底盘姿态修正使用。
- `regular_cross` 和 `_regular` 根据接触点叉乘计算表面法向，消除不希望的法向角速度。
- `control/` 读取谓词输入，`engine/` 提供动力和阻尼，`_seat_*` 管理乘客。

## 测试

```mcfunction
function vve_examples:test_car/test/cp/start
```

测试入口会自动初始化本模块及其依赖，并创建带显示实体和座椅的载具。
