# 其它函数

本页介绍 `data/vve/function/` 根目录中不属于介质探测、打印和自动化测试的公共辅助接口。

| 函数 | 作用 |
| --- | --- |
| `vve:_init` | 初始化 VVE 及内置模块 |
| `vve:_version` | 写入并显示当前 VVE 版本 |
| `vve:_consts` | 恢复默认物理常量表 |
| `vve:_void` | 空回调函数 |
| `vve:_tp_here` | 把执行实体传送到当前执行位置 |
| `vve:_tp_here_macro` | 按宏参数传送执行实体 |

## 1. `vve:_init`

`vve:_init` 是 VVE 的总初始化入口。它完成：

1. 创建 `vve_material_type` 和 `vve_id` 记分板目标；
2. 写入 VVE 使用的整数常量；
3. 调用 `vve:_consts` 设置默认物理环境；
4. 初始化物体、介质响应、模拟器、测试坐标、着色器、ID、自动化测试和声音等内置模块；
5. 初始化 `module_control`；
6. 记录当前初始化版本。

安装或重新加载依赖后执行：

```mcfunction
function math:_init
function math:_init_la
function vve:_init
```

`vve:_init` 不会自动初始化方块读取阵列，也不会初始化可选的图形库。方块读取器需要单独调用 `vve:block_reader/_init`。

### 重复初始化

该函数会再次设置数据模板、常量和部分全局 storage。已存在的记分板目标可能报告“目标已存在”，但后续命令仍会继续执行。不要在物理主循环中重复调用初始化入口。

## 2. `vve:_version`

该函数把当前版本号写入：

```text
version_vve int
```

VVE 3.0.1 对应整数 `301`，同时向当前命令接收者输出版本文本。

可以用它检查依赖版本：

```mcfunction
function vve:_version
execute unless score version_vve int matches 301.. run return run tellraw @a "VVE 版本过低"
```

`vve:_init` 会在初始化末尾调用该函数，并把结果复制到 `vve_init_version int`。

## 3. `vve:_consts`

`vve:_consts` 恢复一整套默认物理环境，包括：

- 空气、流体、水和岩浆的摩擦与浮力参数；
- 实心介质的摩擦和反弹参数；
- 附着层深度、速度过滤和姿态修正参数；
- 重力加速度；
- 实心与斜面介质的几何参数；
- 四类特殊方块材质参数。

自定义模拟器必须先恢复默认值，再覆盖自己的环境：

```mcfunction
function vve:_consts
scoreboard players set vve_gravity int 120
scoreboard players set vve_solid_friction int 9500
```

完整的常量含义和模拟器隔离规则参阅[常量表与模拟器](../基础理论/常量表,%20模拟器.md)。

## 4. `vve:_void`

`vve:_void` 是一个没有任何命令的空函数，用于必须提供函数 ID、但当前不需要执行操作的回调位置。

```mcfunction
data modify storage example:io callback set value "vve:_void"
```

它不读取输入、不产生输出，也没有副作用。

## 5. `vve:_tp_here`

该函数把当前执行实体 `@s` 传送到当前命令执行位置：

```mcfunction
execute as @e[tag=math_marker,limit=1] positioned 10 80 10 run function vve:_tp_here
```

执行后，该实体位于 `(10,80,10)`。函数只改变位置，不改变执行朝向。

它适合把运算实体移动到由 `execute positioned` 建立的上下文中。调用者必须保证 `@s` 是可传送的实体。

## 6. `vve:_tp_here_macro`

该宏函数从 `storage vve:io` 读取 `x`、`y`、`z`，把执行实体传送到对应坐标：

```mcfunction
data modify storage vve:io x set value 10.5
data modify storage vve:io y set value 80.0
data modify storage vve:io z set value -3.25
execute as @e[tag=math_marker,limit=1] run function vve:_tp_here_macro with storage vve:io {}
```

函数先把命令位置设为原点，再使用 `~$(x) ~$(y) ~$(z)`，因此三个参数最终表示绝对世界坐标。

宏参数必须能直接替换为合法坐标文本。缺少字段或字段类型不适合宏展开时，传送命令不会正确执行。

## 7. 范围说明

根目录中的 `call_material` 是介质探测内部调度函数，`test` 是临时调试函数；两者都不符合公共辅助接口命名约定，因此不在本页介绍。根入口 `vve:_test_auto` 属于[自动化测试](自动化测试.md)。
