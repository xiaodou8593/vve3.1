# 打印函数

VVE 在 `data/vve/function/` 根目录提供五个公共打印函数，用于把常见临时对象数据输出到聊天栏。它们都是只读调试接口，不会修改被打印的物理数据。

这些函数读取共享假玩家记分板，因此调用前必须先把目标实例投射或读取到临时对象。

## 1. 函数概览

| 函数 | 读取的数据 | 输出内容 |
| --- | --- | --- |
| `vve:_print_coord` | `x/y/z int` | 临时对象坐标 |
| `vve:_print_coord_as` | `@s x/y/z` | 当前执行实体的坐标记分板 |
| `vve:_print_velocity` | `vx/vy/vz int` | 临时对象线速度 |
| `vve:_print_angular` | `angular_x/y/z`、`angular_len` | 角速度向量及长度 |
| `vve:_print_response` | 介质响应临时对象 | 附着层、反弹层、摩擦、冲量和位移响应 |

输出会发送给所有玩家 `@a`，当前实现没有提供接收者选择参数。

## 2. 坐标打印

### 2.1 `vve:_print_coord`

读取假玩家 `x`、`y`、`z` 在 `int` 记分板中的值：

```mcfunction
function vve:_print_coord
```

输出格式：

```text
xyz: <x>, <y>, <z>
```

常用于 `_proj` 或 `_get` 之后检查临时对象。函数直接输出定点整数，不会自动除以 `10000`。

### 2.2 `vve:_print_coord_as`

读取当前执行实体 `@s` 在 `x`、`y`、`z` 三个记分板目标中的值：

```mcfunction
execute as @e[tag=example_object,limit=1] run function vve:_print_coord_as
```

该函数不读取共享临时对象，适合直接检查实例对象中保存的坐标。

## 3. 速度打印

### 3.1 `vve:_print_velocity`

读取 `vx/vy/vz int`：

```mcfunction
function vve:_print_velocity
```

输出格式：

```text
velocity: <vx>, <vy>, <vz>
```

输出仍是记分板中的定点整数。

### 3.2 `vve:_print_angular`

读取角速度向量和角速度长度：

```mcfunction
function vve:_print_angular
```

输出两行：

```text
angular: <angular_x>, <angular_y>, <angular_z>
angular_len: <angular_len>
```

调用者应先运行会计算或读取 `angular_len` 的对象接口；该打印函数不会自行更新角速度长度。

## 4. 介质响应打印

`vve:_print_response` 输出当前单点或物体级介质响应：

```mcfunction
function vve:_print_response
```

它固定输出：

- `grab_layer_response`；
- `bounce_layer_response`；
- `friction_response`。

当 `impulse_response >= 1` 时，继续调用 `vve:impulse/_print`；当 `shift_response >= 1` 时，继续调用 `vve:shift/_print`。

当前实现不会输出 `material_response`、`surface_response` 或 `couple_response`。函数名中的“所有介质响应”应理解为当前实现选定的主要响应，而不是完整转储全部相关记分板。

## 5. 常用调用流程

打印实例的运动数据：

```mcfunction
execute as @e[tag=example_object,limit=1] run function example:object/_debug
```

```mcfunction
# example:object/_debug
function example:object/_get
function vve:_print_coord
function vve:_print_velocity
function vve:_print_angular
```

打印单次介质探测结果：

```mcfunction
execute as 0-0-0-0-0 at @s run function vve:_detect_material
function vve:_print_response
```

## 6. 注意事项

1. 除 `_print_coord_as` 外，其余函数读取共享临时对象。
2. 输出值保留内部定点整数倍率，打印函数不负责格式化为小数。
3. 输出目标固定为 `@a`，频繁在主循环中调用会产生大量聊天消息。
4. 模块目录中的其他 `_print*` 属于对应模块接口，不在本页公共打印函数范围内。
