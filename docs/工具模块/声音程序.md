# 声音程序

`vve:sound` 是 VVE 的预设碰撞声音程序。它在一次介质探测完成后读取材质、附着层、反弹层和冲量响应，并按材质选择 `playsound`。

源码目录：`data/vve/function/sound/`。

## 1. 初始化和调用

`vve:sound/init` 由 `vve:_init` 调用，创建：

```text
vve_sound_timer
vve_sound_last_bounce
vve_last_material
```

当前源码随后还会调用 `vve:sound/_consts` 和 `vve:sound/_class`，但项目快照中没有提供这两个函数文件。Minecraft 会报告函数不存在，已创建的三个记分板目标不会因此撤销。若在正式项目中复用该初始化入口，应补上空实现或对应的常量、数据模板实现。

主入口：

```mcfunction
function vve:sound/main
```

调用时，当前世界实体必须是执行者 `@s`，并且当前介质响应仍在共享临时对象中。主要输入为：

| 输入 | 用途 |
| --- | --- |
| `bounce_layer_response` | 是否发生反弹层接触 |
| `grab_layer_response` | 是否处于附着层 |
| `material_response` | 材质类型编号 |
| `friction_response` | 摩擦响应，当前主程序保留了摩擦分支 |
| `impulse_response` | 是否存在冲量 |
| `impulse_x/y/z`、`impulse_fx/fy/fz` | 冲量作用点和向量 |

## 2. 反弹声音流程

`sound/main` 先调用 `bounce_check`：

1. 比较 `vve_sound_timer` 与 `vve_sound_last_bounce`；
2. 相隔 `0..5` 次调用时抑制重复声音；
3. 对水、岩浆和液体材质处理材质切换声音；
4. 当 `bounce_layer_response >= 1` 时调用 `sound/bounce`。

`sound/bounce` 把声音位置移动到 `impulse_x/y/z`，计算冲量的 L1 范数，然后按 `material_response` 分派声音：

| 材质响应 | 默认声音 |
| --- | --- |
| 正数实体介质、`-2` 普通实心方块 | 深板岩脚步声 |
| `-3` 类型 1 | 玻璃落地声 |
| `-4` 类型 2 | 沙子脚步声 |
| `-5` 类型 3 | 史莱姆方块脚步声 |
| `-6` 类型 4 | 蜂蜜块脚步声 |

水和岩浆在 `bounce_check` 中分别使用玩家入水声和岩浆气泡声。

## 3. 摩擦声音

`sound/friction` 根据 `material_response` 分派到 `friction_solid`、`friction_liquid`、`friction_type_1` 至 `friction_type_4`、`friction_water` 和 `friction_lava`。

当前 `sound/main` 中调用摩擦声音的代码被注释，且多数 `friction_*` 函数只有占位函数头。因此这些函数是可扩展接口，不代表当前快照已经实现所有摩擦音效。

如果要启用摩擦声音，应在自定义主程序中按计时周期调用：

```mcfunction
execute if score bounce_layer_response int matches 0 \
    if score grab_layer_response int matches 1.. \
    run function vve:sound/friction
```

## 4. 声音状态读写

```mcfunction
function vve:sound/_get
function vve:sound/_store
```

`_get` 把当前实体的三个声音记分板复制到临时对象，`_store` 执行相反方向的复制。

预设声音程序的当前实现直接使用共享假玩家状态。如果多个物体同时调用 `sound/main`，它们会共享计时器和上次材质。需要每个物体独立冷却时，应把声音字段纳入物体对象，并在物体主程序中成对调用 `_get/_store`。

## 5. 自定义声音

可以覆盖以下函数来替换资源包声音或播放位置：

```text
vve:sound/bounce_solid
vve:sound/bounce_type_1
vve:sound/bounce_type_2
vve:sound/bounce_type_3
vve:sound/bounce_type_4
vve:sound/bounce_water
vve:sound/bounce_lava
vve:sound/friction_*
```

自定义函数需要保留调用时的执行位置和实体上下文，否则声音可能在错误的位置播放。
