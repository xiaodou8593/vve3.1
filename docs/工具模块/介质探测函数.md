# 介质探测函数

VVE 在 `data/vve/function/` 根目录提供七个介质探测函数。它们接收一个碰撞点和当前执行位置，查询该位置的世界介质，并把结果写入共享的介质响应临时对象。

介质探测函数只负责单个碰撞点。物体如何生成碰撞点、如何汇总多个碰撞点以及如何应用响应，请参阅[介质探测与介质响应](../基础理论/介质探测,%20介质响应.md)。

## 1. 公共调用约定

### 1.1 执行上下文

调用介质探测函数时需要同时准备：

- 当前执行位置：要查询的碰撞点世界位置；
- 当前执行者：一个可以写入 `Pos` 的世界实体；
- 碰撞点临时对象：位置、速度和质量已经写入共享记分板。

典型调用方式为：

```mcfunction
execute as 0-0-0-0-0 at @s run function vve:_detect_material
```

调用者不能假定执行实体自身的 `Pos` 始终等于当前执行位置。部分探测分支和响应函数会移动这个实体，因此应使用专门的运算实体，不要直接把物理实例或玩家作为临时执行者。

### 1.2 输入

| 输入 | 精度 | 含义 |
| --- | --- | --- |
| `c_x/c_y/c_z int` | `1w` | 碰撞点世界坐标 |
| `c_vx/c_vy/c_vz int` | `1w` | 碰撞点瞬时速度 |
| `c_mass int` | `1` | 计算响应时使用的质量 |

`vve:_detect_liquid` 还需要：

| 输入 | 精度 | 含义 |
| --- | --- | --- |
| `buoyancy_area int` | `100` | 碰撞点代表的浮力面积 |
| `buoyancy_h int` | `1w` | 浮力计算使用的高度 |

### 1.3 输出

每次调用都会先重置主要响应信号，然后根据命中的介质写入：

| 输出 | 含义 |
| --- | --- |
| `material_response` | 命中的介质类型编号 |
| `surface_response` | 是否要求物体执行表面姿态修正 |
| `grab_layer_response` | 附着层响应状态 |
| `bounce_layer_response` | 反弹层响应状态 |
| `friction_response` | 速度保留比例 |
| `shift_response` | 是否产生位移修正 |
| `shift_x/shift_y/shift_z` | 位移修正向量 |
| `impulse_response` | 是否产生冲量 |
| `impulse_x/impulse_y/impulse_z` | 冲量作用点 |
| `impulse_fx/impulse_fy/impulse_fz` | 冲量向量 |

响应保存在共享临时对象中。调用另一个探测函数会覆盖响应信号，因此应在下一次探测前完成接收或复制。

## 2. 函数选择

| 函数 | 适用场景 | 主要差异 |
| --- | --- | --- |
| `vve:_detect_material` | 通用刚体或质点 | 支持实体介质、方块材质、水、岩浆、空气和普通实心方块 |
| `vve:_detect_liquid` | 需要浮力的物体 | 在水和岩浆中计算浮力；还需要浮力面积和高度 |
| `vve:_detect_solid` | 只需要基础方块碰撞 | 不查询实体介质，不加载特殊方块材质参数 |
| `vve:_detect_slope` | 需要内置斜面方块 | 在通用接触流程中增加白桦木活板门斜面探测 |
| `vve:_detect_large` | 需要查询大范围实体介质 | 除普通实体盒体外，还查询 `vve_large_material` 实体 |
| `vve:_detect_box` | 自定义实体盒体碰撞 | 查询实体盒体和流体；未命中时按空气处理，不碰撞普通实心方块 |
| `vve:_detect_render` | 调试碰撞点 | 只调用图形库渲染，不执行常规物理介质响应 |

## 3. 各函数说明

### 3.1 `vve:_detect_material`

这是默认的通用介质探测入口。查询顺序为：

1. 查询当前位置的 `vve_material_box` 实体介质；
2. 查询水和岩浆；
3. 判断 `#vve:pass` 可穿过方块；
4. 根据 `#vve:type_1` 至 `#vve:type_4` 加载特殊材质参数；
5. 对普通实心方块计算接触面、附着层、位移和冲量。

适用于大多数普通刚体和质点模型。

### 3.2 `vve:_detect_liquid`

该函数在水和岩浆响应中加入浮力计算。流体响应会使用 `buoyancy_area` 和 `buoyancy_h`，因此不能把它当成无需额外输入的 `_detect_material` 替代品。

它仍能处理实体介质、空气和实心方块，但普通实心方块使用默认实心介质参数，不加载四类特殊方块材质。

### 3.3 `vve:_detect_solid`

这是基础实心方块探测入口。它可以区分水、岩浆、可穿过方块和普通实心方块，但不会查询实体介质，也不会加载特殊材质参数。

需要确定运行范围、避免物体与实体介质交互时，可以使用此入口。

### 3.4 `vve:_detect_slope`

该函数把特定状态的白桦木活板门解释为内置斜面，并根据朝向计算斜面法线和接触深度。未命中斜面时继续执行普通实心方块探测。

当前斜面实现与具体方块及其 `facing` 状态绑定，并不是任意方块形状探测器。

### 3.5 `vve:_detect_large`

该函数在 `_detect_material` 的实体介质查询基础上，额外搜索带有 `vve_large_material` 标签、距离修正后位于 128 格范围内的实体。

它适合承载范围明显大于普通一格实体盒体的曲面或区域介质。更大的候选范围也意味着更高的实体查询成本，不应无条件替代普通探测入口。

### 3.6 `vve:_detect_box`

该函数用于自定义实体盒体之间的探测流程。它查询当前位置的 `vve_material_box`，并保留水、岩浆及空气摩擦响应；未命中实体介质时不会对普通实心方块产生碰撞。

因此它适合物体之间的动态碰撞补充，不适合作为完整的世界方块碰撞入口。

### 3.7 `vve:_detect_render`

该函数先清空响应信号，再调用：

```mcfunction
function math:_render
```

调用前需要在 `storage math:io render_command` 中提供渲染命令，并安装、初始化 `math3.1_gelib`。它用于显示碰撞点或探测位置，不会产生常规的位移、冲量和摩擦响应。

## 4. 使用示例

下面的示例把当前物体位置转换成碰撞点，然后执行通用探测：

```mcfunction
function example:object/_get_cpoint
execute as 0-0-0-0-0 at @s run function vve:_detect_material

# 在下一次探测覆盖响应前完成接收
function vve:object/_receive_impulse
function vve:object/_receive_shift
function vve:object/_receive_friction
```

刚体通常不直接手写这段流程，而是通过模块的 `_iter_cpoints*` 接口依次生成、探测并接收所有碰撞点。

## 5. 使用限制

1. 探测函数使用共享假玩家和 `storage vve:io`，不能嵌套执行。
2. 执行位置必须与 `c_x/c_y/c_z` 描述的碰撞点一致，否则方块查询与响应作用点会出现偏差。
3. 探测只生成响应，不会自动修改物体状态。
4. `_detect_render` 需要图形库，其余探测函数不依赖图形库。
5. 不同探测入口的覆盖范围不同，应根据模型需要选择，不要默认视为完全等价。
