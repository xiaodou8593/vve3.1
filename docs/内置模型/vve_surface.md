# `vve:surface`

`vve:surface` 是强制姿态规整的响应信号。实现位于 `data/vve/function/surface/`，当前只有 `init`，负责将 `surface_response` 置零。

它没有独立向量负载，实际规整方向通常来自附着层或载具底盘统计得到的 `nvec`。

普通刚体多根据有效附着点数量自行决定是否规整。载具等模型还可以在底盘获得足够支撑点时设置表面状态，使 `_regular` 即使不满足普通附着层条件也运行。

因此，`surface_response` 应理解为控制信号，而不是一种力、位移或材质。自定义介质设置它之前，必须同时保证消费者能取得有效接触法线。
