# 介质响应模型

介质响应模型是介质探测与物体力学迭代之间的数据协议。介质只填写响应，物体决定如何汇总和应用。

## 响应一览

| 信号 | 负载 | 作用 |
| --- | --- | --- |
| `material_response` | 材质编号 | 标识空气、方块材质或实体介质 |
| `shift_response` | `shift_x/y/z` | 修正已经发生的几何穿透 |
| `impulse_response` | 作用点和冲量向量 | 改变线速度，并可能改变角速度 |
| `couple_response` | `couple_x/y/z` | 直接改变角速度 |
| `friction_response` | 速度保留系数 | 衰减整体线速度和角速度 |
| `grab_layer_response` | 法线和深度 | 表示浅层、低速稳定接触 |
| `bounce_layer_response` | 法线和深度 | 表示深层反弹接触 |
| `surface_response` | 无额外负载 | 强制运行物体姿态规整 |

## 单点到物体级响应

每次碰撞点查询只产生一组单点响应。刚体的碰撞点遍历执行：

```text
vve:object/_clear_receiver
  -> 多次调用 _receive_shift/_receive_impulse/_receive_friction/...
  -> vve:object/_receive_over
```

摩擦取最强衰减，位移按轴合并，冲量和力偶矩按有效响应点数量平均，附着层和反弹层累计接触数，法线选择代表性接触。

## 使用原则

- 生成负载时必须同步设置相应 `*_response` 信号。
- 没有信号时，消费者不应读取残留负载。
- 位移用于消除穿透，不等同于速度或冲量。
- 偏心冲量可直接由刚体应用，也可先拆成平动冲量与 `couple`；当前刚体优先使用后者。
- 响应临时对象是共享的，不应跨异步调用长期保存；需要持久化时复制到自己的 storage 或实体数据。
