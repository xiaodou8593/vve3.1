# 其它模型

本节收录不直接代表“运动物体”或“空间介质”，但被两者共同依赖的数据模型和辅助模型。

| 分类 | 模型 | 作用 |
| --- | --- | --- |
| 介质响应 | `couple`、`impulse`、`friction`、`shift`、`shift_origin`、`grab_layer`、`bounce_layer`、`material`、`surface` | 描述一次介质查询或多点汇总产生的物理结果 |
| 碰撞点 | `cpoint` | 统一物体与介质之间的查询输入 |
| 惯性张量 | `tensor` | 保存张量并计算指定转轴的等效惯量 |
| 慢速播放 | `sim_slow` | 把模拟器慢放状态附着到外部实体 |
| 座椅 | `seat` | 用交互实体提供固定宽高的乘坐/交互位置 |

这些模型大多使用全局记分板临时对象，不拥有独立实例生命周期。调用者必须遵守“初始化或清空、写入负载、设置响应信号、及时消费”的顺序，避免上一碰撞点的数据泄漏到下一次查询。

## 响应对象的共同规则

响应通常由两部分组成：

1. `*_response` 记分板信号，表示本次是否存在该响应，或记录响应数量；
2. 对应的向量、作用点、法线、深度或系数负载。

介质探测函数每次查询前会重置信号。刚体遍历多个碰撞点时先把单点响应写入 `vve:object` 的 `receiver`，最后由 `_receive_over` 输出物体级响应。

`material` 已在介质模型中说明，两个分类复用同一篇 `vve_material.md`。
