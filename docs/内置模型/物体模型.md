# 物体模型

物体模型负责保存运动状态、执行运动学与力学迭代，并把介质响应应用到物体。VVE 将公共运算、碰撞点方案、显示方案和实例生命周期拆成可以组合的层，因此本节中的“模型”并不都能直接实例化。

## 1. 模型层次

| 层次 | 模型 | 主要职责 |
| --- | --- | --- |
| 质点 | `vve:point` | 只维护位置和线速度，以自身中心作为碰撞点 |
| 刚体核心 | `vve:object` | 维护姿态、角速度、局部坐标系并应用刚体响应 |
| 标量惯量刚体 | `vve:block` | 为立方体提供八顶点碰撞和单一惯量算法 |
| 张量刚体 | `vve:box_object` | 为长方体提供八顶点碰撞和完整惯性张量 |
| 物体与介质组合 | `vve:cublock`、`vve:cubox` | 既自行运动，也能被其他物体作为实体介质探测 |
| 专用基础组件 | `vve:vehicle` | 在 `cubox` 能力上增加底盘接触、控制与引擎接口 |
| 测试模型 | `vve:test/explode/*`、`vve:block_reader/test/build_model` | 验证爆炸唤醒和方块读取等实验流程 |

## 2. 共同数据

物体通常包含以下状态：

| 数据 | 含义 |
| --- | --- |
| `center` | 质心世界坐标 |
| `velocity` | 质心线速度 |
| `angular_vec`、`angular_len` | 角速度方向与大小 |
| `ivec/jvec/kvec` | 当前局部坐标轴 |
| `xyzw` 等四元数字段 | 当前姿态及一次旋转迭代所需状态 |
| `mass` | 质量 |
| `inertia` 或 `tensor` | 标量惯量或惯性张量 |

坐标、速度和大多数向量按 `10000 = 1` 缩放；角速度字段在部分接口中使用更高精度，具体以各模型的数据表为准。

## 3. 共同接口约定

完整物体模块通常提供：

| 接口 | 作用 |
| --- | --- |
| `_proj` / `_model` | 数据模板与临时对象互相转换 |
| `_get` / `_store` | 实例状态与临时对象互相转换 |
| `_new` / `_del` | 创建和销毁实例 |
| `_iter_cpoints*` | 生成碰撞点并汇总介质响应 |
| `main*` | 执行完整帧、拆分帧或慢速帧 |
| `_sync_motion` | 同步根实体和显示实体 |

`vve:object`、`vve:block` 和 `vve:vehicle` 是基础组件。仓库中的内置目录没有补齐所有 `_class`、`_consts`、实例创建或显示函数，应通过相应 MOT 预设模板生成完整业务模块，不能仅凭目录中的 `init` 当作独立成品模型使用。

## 4. 如何选择

- 只需要平动或需要大量对象时，使用 `vve:point` 模板。
- 需要简单立方体刚体但不需要物体间碰撞时，使用 `vve:block` 模板。
- 需要物体间碰撞时，使用 `vve:cublock` 或 `vve:cubox`。
- 长宽高不同或转动惯量必须精确时，选择 `box_object/cubox` 系列。
- 载具应以 `vve:vehicle` 对应模板为起点，再补充显示、座椅和控制信号。

测试模型使用测试函数前缀，不承诺稳定接口，不应作为通用模块依赖。
