# `vve:solid`

`vve:solid` 负责普通实心方块的最近表面搜索。实现位于 `data/vve/function/solid/`，函数前缀为 `vve:solid/`。它是介质探测内部几何组件，不是可单独创建的模型实例。

## 输入与输出

调用前，探测函数根据碰撞点在方块内部的位置以及六个相邻方块是否可穿过，生成搜索方向 `rx/ry/rz`，每个分量取 `-1/0/1`。

`search` 通过函数宏分派到 27 个方向文件之一：

```mcfunction
$function vve:solid/$(rx)_$(ry)_$(rz)
```

方向函数计算最近可退出表面的：

- 外法线 `nvec_x/nvec_y/nvec_z`；
- 沿法线反方向的侵入深度 `grab_depth`。

后续附着层或反弹层函数再根据这两个结果生成位移、冲量和摩擦。

## 几何意义

搜索不只选择当前方块六个面，还考虑相邻方块是否封闭候选出口。这样碰撞点位于连续实心结构内部时，不会被推向另一个同样实心的相邻方块；边、角和完全包围情形分别由不同方向文件处理。

`vve:solid` 默认把方块视为完整单位立方体。台阶、斜面或其它非满方块需要专用介质模型，不能只依赖这一搜索器得到准确几何。
