# `vve:material`

`vve:material` 管理方块材质分类、物理参数和 `material_response` 信号。它同时属于“介质模型”和“介质响应模型”，两处导航共用本文。

实现位于 `data/vve/function/material/`，函数前缀为 `vve:material/`。

## 材质分类

| 类型 | 默认方块 | 编号 | 物理倾向 |
| --- | --- | ---: | --- |
| `#vve:type_1` | 冰、浮冰、蓝冰 | `-3` | 低摩擦、高速度保留 |
| `#vve:type_2` | 泥土、沙、沙砾、灵魂沙等 | `-4` | 较高阻力 |
| `#vve:type_3` | 史莱姆方块 | `-5` | 较强反弹 |
| `#vve:type_4` | 蜂蜜块 | `-6` | 不反弹、较强黏滞 |
| 未分类实心方块 | 其它不可穿过方块 | `-2` | 使用全局实心介质默认值 |

`#vve:pass` 定义空气、植物、按钮、花、水和岩浆等可由实心几何跳过的方块。

## 参数

每种类型维护五组常量：

| 后缀 | 含义 |
| --- | --- |
| `gf` | 附着层整体摩擦保留系数 |
| `sf` | 深层碰撞整体摩擦保留系数 |
| `gft` | 附着层切向摩擦系数 |
| `sft` | 深层碰撞切向摩擦系数 |
| `sbi` | 反弹映射除数，数值越小通常反弹越强 |

`_consts` 设置默认值；`load_type_1`～`load_type_4` 把对应参数复制到 `stemp_*` 临时量，并设置材质编号。

## 协议角色

`material_response` 不是力的大小，而是本次命中的介质类型。物体响应汇总器和声音程序可以根据它选择代表性材质。`vve:material/init` 只初始化此响应信号，不执行几何探测。

扩展材质时，应同时增加方块标签、常量、加载函数和稳定的负数编号，并确认 `_detect_material` 的匹配顺序。
