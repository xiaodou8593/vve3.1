# 介质模型

介质模型描述“碰撞点当前位于什么环境，以及环境应返回什么响应”。介质只生成材质编号、法线、深度、位移、冲量、摩擦和接触层信息；物体模型负责汇总并应用这些结果。

## 1. 两类介质

| 类型 | 模型 | 特征 |
| --- | --- | --- |
| 实体介质 | `vve:cube`、`vve:cublock`、`vve:cubox` | 用实体保存中心、尺寸和姿态，可以移动或旋转 |
| 方块介质 | `water`、`lava`、`liquid`、`material`、`slope_block`、`solid` | 直接读取世界方块、标签和方块状态，不需要创建实例 |

`cublock/cubox` 同时承担物体与实体介质职责，因此复用各自的物体模型文档。

## 2. 探测协议

介质探测的输入是 `cpoint`：

```text
center   = 碰撞点世界坐标
velocity = 碰撞点瞬时速度
mass     = 本次响应使用的等效质量
```

常用入口为 `vve:_detect_material`、`vve:_detect_liquid`、`vve:_detect_solid`、`vve:_detect_slope`、`vve:_detect_large` 和 `vve:_detect_box`。它们先清空响应，再按实体介质、流体、可穿过方块、特殊材质和实心几何的顺序查询。

实体介质候选带有 `vve_material_box` 标签。`vve:call_material` 根据实体的 `vve_material_type` 调用其 `check_material`；正数 `material_response` 表示实体介质，`0` 表示空气，负数表示方块介质。

## 3. 方块介质编号

| 编号 | 模型 |
| ---: | --- |
| `0` | 空气或可穿过方块 |
| `-2` | 默认实心方块 |
| `-3`～`-6` | `type_1`～`type_4` 特殊材质 |
| `-7` | 水 |
| `-8` | 岩浆 |
| `-9` | 通用液体预留类型 |

实体介质当前使用 `1` 表示 `cube`，`2` 表示 `cublock/cubox`。

## 4. 选择与扩展

- 静态世界方块优先使用方块标签和材质参数，成本最低。
- 需要旋转、移动或自定义范围时使用实体介质。
- 自定义实体介质应实现 `check_material`，并通过模块控制接口让 `vve:call_material` 可调用。
- 几何与材质应分开考虑：几何决定是否命中、法线和深度；材质决定摩擦、反弹和声音等参数。
