# 自动化测试模板

自动化测试模板把测试场地搭建、测试实例生命周期、逐帧记录和结果比较文件叠加到一个兼容的物体模块上。

本分类包含：

| 模板 | 用途 |
| --- | --- |
| `vve_test_1.0` | 一次添加碰撞点、自由落体、推力、浮力和物体间碰撞五组预设测试 |
| `vve_test_custom_1.0` | 根据 `test_name` 参数生成一组可自行填写的测试脚手架 |

## 运行依赖

测试文件依赖以下项目能力：

- `math3.1_gelib` 的轨迹或响应可视化；
- `vve:test_coord` 管理测试场地坐标；
- `vve:test_auto` 依次运行测试并比较帧数据；
- `marker_control` 调度测试实例并在超时后销毁；
- 被测模块提供 `_class`、`_proj`、`_model`、`_new`、`main_c`、`_poke_here_i_as` 等刚体接口。

测试会在世界中清理和填充一个小型场地、召唤实体并写入测试帧数据，只应在专用测试区域运行。

## 结果基线

每组测试的 `store_frame` 负责保存当前状态，`frame` 保存或比较期望帧，`start/main/end` 管理生命周期。修改物理常量、碰撞点或迭代顺序后，应重新审核基线，而不是只以测试是否结束作为正确性标准。

## 运行测试方法

```
function <module_prefix>test/<test_name>/start
```

## 结束测试方法

```
scoreboard players set test int 1
```
