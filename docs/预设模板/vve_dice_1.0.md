# `vve_dice_1.0`

`vve_dice_1.0` 是骰子功能模板，为已有标量惯量刚体增加随机姿态、投掷、读值、输出和均匀性测试接口。

模板源码位于 `memory_storage/vve_dice_1.0/`。它不提供质量、碰撞点、显示模型或主程序，必须叠加到兼容物体模板。

## 默认几何

当前方向表包含八个归一化方向，并把它们映射到点数 `1..8`。因此模板默认更接近八面骰功能层，不是无需修改即可适配任意面数的通用骰子。

以下三个接口各自保存了一份方向表，定制骰子时必须保持一致：

| 接口 | 使用方向表的目的 |
| --- | --- |
| `_get_value` | 把局部方向转换到世界坐标，选择 `y` 最大的朝上面 |
| `_rand_quat` | 随机选择一个方向，再随机绕该方向旋转 |
| `_set_quat` | 按 `inp` 拆分方向索引和面内旋转，生成固定姿态 |

## 投掷接口

`_roll` 从模块默认数据模板创建骰子，生成随机四元数，并根据调用位置和朝向施加一次偏心冲量。`_roll_fixed` 使用 `inp` 指定的固定姿态，便于重复实验。

创建后的骰子交给 `marker_control`：120 tick 后调用 `_print_value_as` 输出点数并销毁。`_quat_test` 和 `_rand_test` 会批量投掷，用于检查方向映射或随机均匀性。

## 前置契约

被叠加模块需要提供：

- `_class`、`_new`、`_get`、`_store`；
- `a`、质量、姿态、角速度和局部坐标字段；
- `vve:block/_apply_impulse` 兼容的标量惯量临时对象；
- 正常物理调度和碰撞点实现；
- `marker_control` 的实例数据与销毁调度。

调用 `_roll*`、`_rand_quat` 和 `_set_quat` 时还需要一个可移动的世界实体作为执行者；模板会临时修改它的 `Pos` 来进行朝向计算，玩家不适合作为这一工作实体。

## 自定义要求

制作其他面数骰子时，应同时修改方向表、点数表、稳定姿态规则和碰撞点几何，并重新运行均匀性测试。只替换显示模型不会让读值或物理落面自动匹配新形状。
