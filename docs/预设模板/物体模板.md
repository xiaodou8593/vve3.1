# 物体模板

物体模板用于通过 MOT 生成可保存状态、接受物理迭代并创建实体实例的模块。它们不是游戏运行时的数据模板，而是构建数据包时展开为 `.mcfunction` 文件的代码模板。

大多数物体模板会生成同一组基础接口：

| 接口 | 作用 |
| --- | --- |
| `init` | 创建记分板、加载常量并生成默认数据模板 |
| `_class` | 生成 `storage <namespace>:class <module>_plate` |
| `_new` / `_del` | 创建或销毁实例 |
| `_get` / `_store` | 在实例对象与共享临时对象之间搬运数据 |
| `_proj` / `_model` | 在数据模板与共享临时对象之间转换 |
| `main*` | 执行运动、介质探测、响应与同步中的一个或多个阶段 |
| `tick` | 遍历模块实例并调用默认主程序 |

## 模板选择

| 模板 | 运动模型 | 碰撞点与介质能力 | 显示实体 |
| --- | --- | --- | --- |
| `vve_point_1.0` | 质点，仅平动 | 质心单点探测 | `item_display` |
| `vve_fixed_object_1.0` | 固定姿态刚体 | 用户定义的固定碰撞点，默认文件给出八顶点实现 | `item_display` |
| `vve_block_1.0` | 标量惯量刚体 | 用户定义的固定碰撞点，不充当实体介质 | `item_display` |
| `vve_block_b_1.0` | 同 `block` | 同 `block` | 目标为 `block_display`，当前快照存在创建类型异常 |
| `vve_box_object_1.0` | 惯性张量刚体 | 用户定义的固定碰撞点，不充当实体介质 | `item_display` |
| `vve_cublock_1.0` | 标量惯量刚体 | 盒体动态碰撞点，可充当实体介质 | `item_display` 乘客 |
| `vve_cublock_b_1.0` | 同 `cublock` | 同 `cublock` | `block_display` 乘客 |
| `vve_cubox_1.0` | 惯性张量刚体 | 可主动探测盒体介质；当前快照的被查询注册不完整 | `item_display` 乘客 |
| `vve_vehicle_1.0` | 载具专用张量刚体 | 盒体与底盘接触点，带控制和座椅 | `item_display` 乘客 |
| `vve_vehicle_lite_1.0` | 轻量载具 | 与标准载具相同的主要物理流程 | 根实体即 `item_display` |
| `vve_singular_1.0` | 标量惯量近似球陀螺 | 碰撞点由用户实现，不充当实体介质 | `item_display` |
| `vve_singular_s_1.0` | 同 `singular` | 用户实现碰撞点，并带盒状实体介质探测能力 | `item_display` 乘客 |

`vve_box_object_b_1.0`、`vve_cubox_b_1.0`、`vve_tensor_object_1.0` 与 `vve_tensor_object_s_1.0` 当前处于施工中。

## 共同约束

- 物理数据使用记分板定点数；字段精度以模板中的 `.doc.mcfo` 为准。
- `_get` 到 `_store` 之间使用的是全局共享临时对象，不能嵌套处理另一个实例。
- 模板中的显示物品、默认尺寸、质量和材质编号只是占位配置，实际模块通常需要覆盖 `_class`、`_new` 或 `set_operation`。
- `main`、`main_c`、`main_l` 分别代表不同的介质探测/响应方案；模块应只调度符合自身需求的入口。
- `*_b` 表示为 `block_display` 调整显示更新与运动同步，不代表新的物理模型。
