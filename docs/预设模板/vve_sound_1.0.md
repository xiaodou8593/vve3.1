# `vve_sound_1.0`

`vve_sound_1.0` 是碰撞声音功能模板。它读取当前介质探测产生的材质、反弹层、附着层、摩擦和冲量响应，在碰撞点位置播放对应声音。

模板源码位于 `memory_storage/vve_sound_1.0/`。它只增加 `sound/` 子目录，不定义对象数据、实例或调度入口。

## 调用契约

`sound/main` 需要在一次介质探测完成、相关临时响应仍然有效时调用，并要求世界实体为执行者。主要输入包括：

- `bounce_layer_response`、`grab_layer_response`；
- `material_response`、`friction_response`；
- `impulse_response` 及冲量作用点和向量；
- `vve_sound_timer`、`vve_sound_last_bounce`、`vve_last_material`。

模板本身不初始化这些记分板。模块应调用内置 `vve:sound/init`，或在自己的 `init` 中创建并设置它们。

## 默认声音映射

| 材质响应 | 默认反弹声音 |
| --- | --- |
| 普通实体介质或实心方块 | 深板岩脚步声 |
| 类型 1 | 玻璃落地声 |
| 类型 2 | 沙子脚步声 |
| 类型 3 | 史莱姆方块脚步声 |
| 类型 4 | 蜂蜜块脚步声 |
| 水 | 玩家入水声 |
| 岩浆 | 岩浆气泡声 |

反弹检查在当前计时与上次反弹计时之差为 `0..5` 时直接返回，因此两次反弹声音至少间隔 6 次 `sound/main` 调用。附着层持续接触时，每 5 次计时尝试调用摩擦声音。

## 当前完整性

多数 `friction_*` 文件以及 `bounce_liquid` 当前只有函数头，没有实际 `playsound`；它们是留给项目作者补充的占位实现。`sound/main` 末尾计算了 `% 10` 的临时值但未继续使用，也是当前快照中的遗留代码。

声音函数直接读写共享假玩家。功能模板本身没有把这些值加入被叠加模块的 `_this`，也没有自动调用内置 `vve:sound/_get/_store`。因此原样调用时，多个物体会共享冷却和上次材质状态；需要独立声音状态时，应扩展对象格式并把声音状态的读取、保存合并进物体主程序。
