# `vve_block_1.0`

`vve_block_1.0` 是使用标量惯量的刚体骨架模板。它维护完整姿态和角速度，默认以八个顶点探测世界介质，但自身不注册为盒状实体介质。

模板源码位于 `memory_storage/vve_block_1.0/`，核心计算复用内置 `vve:object` 与 `vve:block`。

## 数据与默认模板

| 字段 | 默认值 | 含义 |
| --- | ---: | --- |
| `a` | `0.25` | 默认实现使用的半边长 |
| `mass` | `17` | 质量 |
| `inertia` | `5.00` | 绕任意方向使用的标量惯量 |
| `center` / `velocity` | `0` | 位置与线速度 |
| `angular_vec` / `angular_len` | `0` | 角速度向量与长度 |
| `ivec/jvec/kvec`、四元数 | 单位姿态 | 局部坐标与旋转状态 |

标量惯量计算成本较低，但不能表达长方体绕不同轴旋转时的惯量差异。

## 碰撞点与主程序

`_iter_cpoints*` 当前给出边长 `2a` 的八顶点实现，可由模块作者替换成任意固定碰撞点模型。

默认 `tick` 调用 `main_c`。该入口除普通介质响应外，还汇总力偶和外部冲量，因此适合完整刚体运行。其他入口包括：

| 入口 | 用途 |
| --- | --- |
| `main` | 普通介质探测，不汇总实体介质力偶 |
| `main_c` | 完整碰撞、力偶与外部冲量流程 |
| `main_l` | 加入流体浮力参数 |
| `main_force` | 只执行力学迭代 |
| `main_slow_mov` / `main_slow_key` | 拆分运动与关键物理步 |
| `main_sync` | 只执行运动同步 |

## 实例与接口

`_new` 直接创建一个 `item_display` 根实体。`set_operation` 默认放入命令方块物品。通用对象接口之外，模板提供 `_poke_here_i_as`、四种碰撞点遍历接口以及 `_update_display`。

`_update_display` 按 `a` 设置三轴等比缩放；姿态和位置由 `vve:object/_sync_motion` 同步。

## 使用边界

该模板能与世界方块、流体和已注册实体介质发生响应，但创建出的实例本身没有 `vve_material_box` 身份，其他物体不会把它当成盒体介质。需要双向物体碰撞时使用 `vve_cublock_1.0`。

快速开始中的 `inter_bounce` 测试因此会穿透，这是模板能力边界，不是测试框架故障。
