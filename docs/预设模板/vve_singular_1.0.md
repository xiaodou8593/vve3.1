# `vve_singular_1.0`

`vve_singular_1.0` 是用于自定义碰撞点的近似球陀螺模板。它使用标量惯量和完整刚体姿态，目标是让多面体、近似球体或陀螺类物体由作者自行定义接触点，同时复用统一的运动、响应与着陆姿态归正框架。

模板源码位于 `memory_storage/vve_singular_1.0/`。

## 数据与默认值

数据结构与 `vve_block_1.0` 相同：`a`、质量、标量惯量、位置、线速度、角速度、局部坐标系和四元数。默认 `a=0.25`、质量 `17`、惯量 `5.00`。

`a` 是模板默认计算使用的几何尺度，不限定用户最终碰撞点的数量或形状。

## 自定义碰撞点

`_iter_cpoints`、`_iter_cpoints_c` 和 `_iter_cpoints_l` 是需要用户实现的主要位置。当前文件只保留“顶点 1”和省略号占位，不能视为已经完成的单碰撞点模型。

实现自定义碰撞点时，每个点需要提供：

- 相对质心的位置；
- 由线速度与 `angular_vec × r` 合成的点速度；
- 碰撞点质量；
- 对普通、力偶和流体三种遍历入口分别适配的响应汇总。

## 姿态归正

`_regular` 与 `regular/surface_1` 至 `surface_8` 提供八个候选稳定姿态的归正框架。它根据接触法线和局部方向选择目标表面，通过四元数修正姿态并消除法向角速度。

这套规则同样属于可定制内容。多面体的稳定面数量、法线方向或陀螺行为与默认八面规则不一致时，应覆盖 `_regular` 及对应 `regular/*`。

## 实例与边界

实例是单个 `item_display`，默认物品为命令方块，不注册为实体介质。默认 `tick` 调用 `main_c`；只有在用户完成碰撞点实现后，介质探测和力偶响应才具有实际意义。

该模板不是“只有一个碰撞点”的成品模型，而是自定义碰撞点近似球陀螺的骨架。
