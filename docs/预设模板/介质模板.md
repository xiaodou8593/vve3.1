# 介质模板

介质模板用于构建占据世界空间、接收碰撞点查询并返回物理响应的模块。介质与物体是两种不同职责：物体主动推进运动，介质回答“当前位置命中了什么、法线在哪里、应产生怎样的位移、冲量和摩擦”。

当前预设只提供 `vve_material_1.0`，用于构建可移动、可旋转的盒状实体介质。静态方块介质由 VVE 的方块标签与内置 `water`、`lava`、`solid` 等函数处理，不需要通过该模板实例化。

## 实体介质协议

自定义实体介质需要完成以下链路：

1. 实例带有 `vve_material_box`，使 `_detect_box` 能找到它；
2. `vve_material_type` 为内置编号，或实例保存可由 `module_control` 分派的 `module_id`；
3. 模块实现 `check_material`；
4. 命中时设置 `material_response`，并写入位移、法线、冲量、摩擦等响应临时对象；
5. 如需反作用力，实例还要提供 `vve_impulse_receiver` 与对应的消费流程。

## 使用原则

- 几何范围由 `scale`、局部坐标系与 `check_material` 决定；材质参数由 `response` 决定。
- 介质实例可以移动，但 `vve_material_1.0` 的默认 `main` 不主动执行运动学迭代。
- `material_response` 的正数可用作自定义实体介质编号；编号应在项目内保持稳定。
- 自定义介质和物体共用全局临时响应对象，查询过程不能嵌套。
