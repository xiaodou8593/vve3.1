# 其它模板

本节收录不单独定义运动物体或空间介质的模板。除 `vve_simulator_1.0` 外，它们大多是功能层，需要叠加到一个已经提供相应数据和接口的模块骨架上。

| 模板 | 类型 | 主要用途 | 典型前置 |
| --- | --- | --- | --- |
| `vve_response_1.0` | 响应辅助层 | 初始化并打印自定义响应对象 | 已定义 `_this` 的响应模块 |
| `vve_dynamic_cpoint_1.0` | 碰撞功能层 | 为刚体增加盒状实体介质查询 | 带刚体和 `scale` 字段的物体模板 |
| `vve_simulator_1.0` | 独立调度骨架 | 保存时间状态、常量环境与回调列表 | VVE 模拟器基础函数 |
| `vve_sound_1.0` | 声音功能层 | 根据介质和碰撞响应播放声音 | 已执行介质探测的物体模块 |
| `vve_engine_1.0` | 载具功能层 | 沿局部前向施加动力 | 载具字段、底盘接触点与阻尼函数 |
| `vve_test_1.0` | 测试功能层 | 添加五组预设物理测试 | 兼容的刚体模块与图形库 |
| `vve_test_custom_1.0` | 测试脚手架 | 生成一个命名的自定义测试目录 | 同上 |
| `vve_dice_1.0` | 骰子功能层 | 随机姿态、投掷、读值和均匀性测试 | 标量惯量刚体与实体生命周期工具 |

## 叠加规则

MOT 会按路径叠加模板，后加入的同名文件会覆盖前一层，而不会自动合并函数内容。因此：

- 添加前先检查功能模板是否包含 `init`、`main` 或其他骨架已有文件；
- 需要同时保留两层逻辑时，应手动合并，而不是依赖压栈顺序；
- 功能模板通常假定特定记分板、storage 和接口已经存在，必须核对其前置契约；
- `memory_storage` 中的占位代码和省略号需要在生成模块后补全。

模板叠加适合复用一组文件，不等同于面向对象语言中的继承或依赖自动解析。
